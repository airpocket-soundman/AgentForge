1. 概要

AgentForge は、自然言語でアプリを育てると、裏側で AI エージェント群が DevOps を回す「DevOps AI Agent Workbench」です。

一言で言うと

ユーザーがチャットで「タスク管理を追加して」と言うだけで、AI が 設計 → 実装 → テスト → デプロイ → 承認 → 巻き戻し までを代行し、アプリ自身が機能を増やしていきます。

評価してほしいのは「機能の完成度」ではなく「機能が追加されるプロセスそのもの」。 生成されるタスク管理画面は、AgentForge の自己拡張能力を示すための題材です。

二層の建て付け

最大ターゲット（背景）

自己拡張型スーパーアプリ基盤 ＝ DevOps の民主化。非エンジニアでも言葉でアプリを育て続けられる世界。

提出版フォーカス（今回作る）

1 機能（タスク管理）で「チャット→計画→生成→preview→承認→active→rollback」を1 サイクル完走させる。

提供価値の三角形

観点内容
ユーザー体験自然言語でアプリを育てる
技術的価値AI エージェントが DevOps サイクルを代行する
主張AI が価値の中心であり、判断・分解・委任・デプロイ・運用まで一貫制御する

対象ユーザーと課題

  • ペルソナ：社内の非エンジニア業務担当者
  • 課題：簡単な社内ツールを自分で作れず、毎回エンジニアへの開発依頼で待たされる
  • 価値：言葉で頼むだけで機能が増え、要らなければ安全に戻せる

“AI エージェントである必然性”

決め打ちの CI/CD 自動化と違い、曖昧な自然言語要求から「何を作り・どう分解し・どのワーカーに振るか」を非決定的に判断する必要がある。だからこれは単なる自動化ではなく エージェント である。
