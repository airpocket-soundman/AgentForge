11. 実装フェーズ

各フェーズは「何が動けば次へ進めるか」で区切る。Phase 2 で必須要件（Cloud Run＋Gemini＋デプロイ URL）を満たし、一度“提出可能な最小形”に到達する。

Phase内容ゴール状態
0GCP/Firebase 基盤セットアップgcloud run deploy が通る空サービス進行中
1Web Shell + Receptionログイン → チャット → 即応予定
2Orchestrator + Gemini + Control Plane作業計画生成 → registry pending（最小提出可能）予定
3Worker + Cloud Tasks + 生成UI manifestチャットから画面が preview 表示予定
4承認 → active 化 → Task APIタスクの追加/一覧/完了が動く予定
5Rollback + Audit + 権限分離「戻して」で消え、ログが残る予定
6CI/CD + 仕上げpush で本番更新予定
7提出物デモ動画・ProtoPedia・提出予定

MVP の縦切り 1 本

ログイン →「タスク管理を追加して」→ 計画 → manifest 生成 → preview 表示 → 承認 → active → タスク CRUD → 「進捗どう？」即答 → 「戻して」で rollback → Audit Log。これが 1 周動けば提出の核は完成。
