4. 自己拡張フロー

本ページは現行実装のサイクル概観。ワーカー別の詳細フロー図（11ステップ・差し戻しループ含む）は 5b. ワーカー定義・運用ルール の図 3-1 が正本です。

「計算機を作って」の一言から、受付確認 → 設計案 → 生成 → 検証・レビュー → プレビュー → 公開 → 版保存・巻き戻しまで。人間の承認ゲートは 3 つ、公開前に必ず Tester＋Reviewer を通ります。

図 4-1. 現行の自己拡張サイクル。緑の外側ループ＝公開済みアプリの中からさらに次の改変が生まれる再帰構造。

安全装置（このサイクルに組み込み済み）

  • 3つの人間ゲート：お願い／これで作って／反映して。AI は勝手に公開しない。
  • 未完成は公開不可：ゲート不合格・stub（生成失敗）には「反映して」を出さず、公開も拒否。
  • 巻き戻し：公開ごとの版スナップショットから直前版へ即時復元（LLM 不使用・分岐なし）。
  • 停滞監視：ハートビート（進捗報告）が途絶えたときだけ停滞と判定し、工程・最後の動き・無音秒数をチャットに明示。
